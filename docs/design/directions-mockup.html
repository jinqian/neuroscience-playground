Neuro Playground · design proposal

Four ways to learn the brain, one lesson shown each way

Built around the 10 modules of an introductory online neurobiology course. Each mockup below shows the same moment, Module 2's action potential, so you can compare the feel directly. The brain.dev and Case Files mockups are clickable.

What the course looks like

10 modules, about 19 hours of video

Video-heavy. Modules are runs of 2–12 min videos. Module 3 alone is 3h 26m. Long passive stretches are where focus slips.
A built-in story hook. Every subsection ends in a "Practical Scenario", and several modules have clinical vignettes. That's a ready-made case format.
Strong mechanisms. Action potentials, the vestibulo-ocular reflex, motor unit recruitment and basal ganglia loops are all systems you can simulate.

Synapse Quest

Duolingo-style

A winding path of 3–5 minute lessons per module, with a mascot (Dendri the neuron), XP, a daily streak and hearts. Each lesson mixes a tiny illustrated explainer with quick questions: fill the gap, tap the right part, order the steps.

  • Bright, rounded, chunky buttons; one idea per screen
  • Unit check at the end of each module mirrors the graded quiz
  • Spaced review lessons resurface what you got wrong

Trade-off: great for the habit and for memorizing facts. Mechanisms get chopped into small pieces, so the "how it works" picture can feel thin unless lessons also carry simulations.

Plate II · The Neuron

Field note

Action potential. n. A brief, all-or-none flip of the membrane voltage, from about −70 mV to +40 mV and back, that travels down the axon without fading.

Why myelin? The signal hops between the gaps (nodes of Ranvier) instead of crawling. Demyelination (MS) = signal leaks and slows.

Field Guide

Illustrated notebook

Each module is a set of richly drawn plates you explore by tapping. Labels open short notes, and you collect plates and write your own margin notes. Calm and unhurried, closer to a beautiful textbook you play with.

  • Graph-paper and ink look, hand-lettered labels
  • Every plate ends with "draw it from memory" recall prompts
  • Your notes build up into your own personal neuro atlas

Trade-off: best for deep focus and anatomy (Modules 1, 3, 5, 6). Weak on momentum: no streaks or game pressure, so it relies on your own curiosity. Also the most illustration work to produce.

brain.dev

Developer lab

Neuroscience explained as systems you already understand: neurons as stateful objects, synapses as message queues, reflexes as event handlers, the cerebellum as an error-correcting controller. Every lesson has a live simulation you poke at. Drag the slider to find the threshold.

  • "Analogy, then where it breaks" boxes keep the metaphors honest
  • Optional challenges: tune VOR gain, fix a Parkinsonian loop
  • Fits the course's strongest mechanism modules (2, 6, 7, 8, 9)

Trade-off: the most satisfying for a curious developer, but code metaphors can mislead (brains aren't programs), and anatomy-heavy modules fit it poorly.

Case Files

Clinical detective

Each module opens with a patient mystery built around the course's Practical Scenarios and vignettes. You unlock clues by learning the concept behind them, then make the call: where's the lesion, which nerve, which drug. The lessons are what you need to solve the case.

  • Narrative pull: you want to know what's wrong with Mr. T.
  • Teaches the course's main skill: linking symptoms to structure
  • A "casebook" of solved files doubles as your review deck

Trade-off: very engaging and close to how the course itself thinks, but it needs careful scenario writing, and cellular topics (Module 2) don't map neatly onto patients.

My recommendation

A's frame, with C and D as lesson types

Use Synapse Quest as the shell, because short sessions, a visible path and a streak are what fight drifting attention. Inside it, use three kinds of lesson so it never feels like flashcards only:

Bite3 min: an illustrated explainer card plus 4–6 quick questions. Most lessons.
Lab5–8 min: a brain.dev simulation with a goal ("find the threshold", "tune the VOR"). One or two per module.
CaseModule finale: a Case File that uses everything in the unit. Replaces the boring "unit test".

Field Guide plates (B) can come later as a reference "atlas" view, unlocked as you go.

Implementation sketch

How I'd build it

Local web appVite + React + TypeScript, run with npm run dev. Works offline, no account, no server.
Content as filesOne folder per module; lessons in Markdown + JSON question sets, so you can read, fix or add to them like code.
Sims as componentsEach Lab is a React component on canvas/SVG with a small, tested model (e.g. a simplified membrane model).
Progress in the browserXP, streak and review queue saved locally (spaced repetition for missed questions).

Phase 1 · One full unit

Shell (path, lesson player, XP/streak) plus all of Module 2: about 6 Bites, the threshold Lab and one Case. You use it for a week and tell me what works.

Phase 2 · Review + polish

Spaced review lessons, mascot reactions, illustrations style locked in, sound effects optional.

Phase 3 · Remaining modules

One module per batch, following the course order (M1, M3 … M10), each with its Labs and Case.

Later, if wanted

Field Guide atlas; an "ask the tutor" button that explains a card a different way using the Claude API.

On content: the course's module structure is the syllabus and scientific scope. I'd write original explanations and questions on those topics instead of copying course material, and flag anything you should check against the videos.
