# 3D Neuron Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/neuron` screen with a rotatable, code-generated typical neuron: tappable parts, plus a signal animation with and without myelin.

**Architecture:**
- Part text lives in `content/neuron.yaml`, loaded into the content bundle and validated against the model's part list.
- Pure modules `src/neuron/shape.ts` (geometry description) and `src/neuron/signal.ts` (pulse timing) are unit-tested.
- `NeuronCanvas.tsx` (react-three-fiber, lazy-loaded) draws them.
- `NeuronScreen.tsx` holds the controls and the info panel, with a list fallback when there is no WebGL.

**Tech Stack:** React 19, TypeScript, three, @react-three/fiber, @react-three/drei, zod, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-3d-neuron-design.md` (plus the main spec, `2026-11-19-neuro-playground-design.md`).

## Global Constraints

- Neuroscience only: no developer metaphors in any text.
- Every new glossary term has `wiki: { en: … }`, checked to resolve.
- English only (`ENABLED_LANGUAGES = ['en']`). All user-visible strings go in `src/i18n/ui.en.ts` or `content/`.
- Colours:
  - base grey `#d5d9e0` (reuse `BASE` from `src/brain/visual.ts`)
  - the selected part in its own colour
  - hover shows a 40% lighter tint of it
- 3D code is lazy-loaded.

## Review Focus

- No WebGL: the screen must still list and explain every part.
- Toggling **Remove myelin** while a signal is playing must restart or adapt the pulse cleanly, never leave it stuck mid-axon.
- A selected part that becomes hidden (myelin removed while myelin is selected) must not leave a dangling highlight.
- Content: a part in `neuron.yaml` that is missing from the model, or a model part with no text, must fail the content check.
- Phone width: the controls wrap and the page has no horizontal scroll.

### Task 2: Shape and signal

**Files:**
- Create: `src/neuron/shape.ts`
- Create: `src/neuron/signal.ts`
- Test: `src/neuron/neuron.test.ts`

**Interfaces:**

`shape.ts`:
- `NEURON: { soma: {center, radius}, nucleus: {center, radius}, hillock: {from, to, r0, r1}, axon: Vec3[], myelin: {from:number,to:number}[], nodes: number[], dendrites: Vec3[][], terminals: Vec3[][], route: { dendrite: Vec3[], axonStart: Vec3 } }`.
- Distances along the axon are measured from the axon start.
- `PART_COLORS: Record<NeuronPartId,string>`.
- `pointAlong(points: Vec3[], d: number): Vec3`.
- `polylineLength(points): number`.

`signal.ts`:
- `type Phase = 'dendrite'|'soma'|'axon'|'terminal'|'done'`.
- `signalAt(t: number, opts: { myelinated: boolean; lengths: { dendrite, soma, axon, terminal }; nodes: number[] }): { phase: Phase; d: number }`, where `d` is the distance within the phase.
- `signalDuration(opts): number`.

**Steps:**
- [ ] **Failing tests:**
  - With myelin, every sample in the axon phase has `d` equal to one of `nodes`.
  - Without myelin, axon-phase `d` grows smoothly and isn't restricted to nodes.
  - Without myelin, the duration is ≥ 3 × the duration with myelin.
  - After the duration, the phase is `done`.
  - `d` never decreases over time.
  - Shape: the myelin segments don't overlap; every node lies in a gap between segments; the 8 part colours are distinct and differ from `BASE`.
- [ ] **Implement:**
  - Speeds (units/s): 2.5 before and after the axon.
  - Node dwell: 0.18 s per node, with myelin.
  - Without myelin: 0.6 units/s along the axon.
- [ ] **Commit:** `feat(neuron): neuron shape and signal timing`.
